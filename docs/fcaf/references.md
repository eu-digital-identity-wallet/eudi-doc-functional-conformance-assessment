# References

This page provides an overview of the standards and technical specifications (STS) relevant to the FCAF. It includes both the STS covered by tests and the STS that define the tests themselves.

The syntax follows that used for the EUDI Wallet Architecture and Reference Framework (ARF). The Version column records the specification version used for conformance assessment. A hyphen indicates that no specific version is pinned.
