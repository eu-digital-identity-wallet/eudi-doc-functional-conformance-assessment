# FCAF submitted content

This branch contains submitted Functional Conformance Assessment Framework content
under `docs/fcaf/`.

Open content pull requests against `submitted`. Open site, theme, build, CI, and
repository-governance pull requests against the `site` branch of the public repository.

The rendered draft is published at
[conformance.eudi.dev/draft](https://conformance.eudi.dev/draft/).

For project guidance and release information, see the `site` branch of the public
repository.
